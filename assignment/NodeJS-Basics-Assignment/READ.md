# NodeJS Basics Assignment

## Assignment Description

This assignment demonstrates basic Node.js programs using JavaScript.

The assignment contains:

* A program that prints messages in the terminal.
* A program that prints a personal introduction.

## Files

* `app.js` - First Node.js program
* `introduction.js` - Personal introduction program

## Steps to Run

1. Open the project folder in Terminal.
2. Run the first program:

```bash
node app.js
```

3. Run the introduction program:

```bash
node introduction.js
```

## Commands Used

```bash
node app.js
node introduction.js
```
