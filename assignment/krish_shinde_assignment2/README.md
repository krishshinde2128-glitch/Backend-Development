# Node.js HTTP Server Assignments

This repository contains a series of five distinct Node.js server applications built for a backend development assignment. The core objective of these assignments is to demonstrate proficiency using the built-in Node.js `http` module without relying on external frameworks like Express.

## Project Structure

The project consists of 5 separate JavaScript files, each fulfilling a specific set of requirements:

*   **`assignment1.js`**: A basic HTTP server that displays a welcome message.
*   **`assignment2.js`**: An HTML response server that renders a structured Student Portal page.
*   **`assignment3.js`**: A simple REST-like endpoint returning a JSON object for a specific route (`/student`).
*   **`assignment4.js`**: A multi-route server handling basic text responses for various paths (`/`, `/about`, `/contact`, `/services`).
*   **`assignment5.js`**: A comprehensive personal portfolio server featuring a navigation menu, inline styling, and multiple HTML pages rendered via server-side routing.

## Prerequisites

To run these files, you must have [Node.js](https://nodejs.org/) installed on your machine.

## How to Run the Servers

Each assignment is designed to run independently on **Port 3000**. 

1. Open your terminal and navigate to the project directory.
2. Run an assignment file using the `node` command. For example:
   \`\`\`bash
   node assignment1.js
   \`\`\`
3. Open your web browser and navigate to: [http://localhost:3000](http://localhost:3000)
4. **Important:** Because all servers use the same port, you must stop the current server before starting the next one. To stop a running server, press \`Ctrl + C\` in your terminal.
